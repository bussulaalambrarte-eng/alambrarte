# Alambrarte · Brújula y Plan de Producción y Embarque

- `index.html` — app de apuntes (perfiles PROD y ADMIN). Datos en el servidor Google Apps Script.
- `reporte.html` — reporte en vivo, solo visualización (ADMIN).
- `brujula.html` — Brújula Alambrarte: resumen en vivo de Producción y Embarque, áreas del ecosistema y plan de acción (ADMIN).

Las contraseñas se comunican por separado; no se escriben en este repositorio.
Los datos no están en este repositorio: viven en la planilla Google del servidor.
